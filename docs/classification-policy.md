# Classification Policy

## 目的
家計簿アプリ向けに、レシート情報をカテゴリ分類する。

## 現在の対象
- 店舗名正規化
- 店舗単位分類
- 明細キーワード分類
- needsReview 判定
- confidence 算出

## まだ対象外
- OCR API接続
- 画像アップロード
- DB保存
- ログイン
- UI
- 本番運用

## カテゴリ
- 食費
- 日用品
- 交通
- 医療
- 通信
- 娯楽
- 教育
- その他

## 危険店舗
以下は店舗名だけで分類確定しない。

- Amazon
- 楽天
- イオン
- ドンキホーテ
- メルカリ

## 基本ルール
1. ユーザー修正ルールを最優先
2. 店舗名ルール
3. 明細キーワードルール
4. 曖昧店舗は needsReview=true
5. 分類不能も needsReview=true
